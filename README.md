# RDT-Solar — RDT We Do It All

Modern, 3D interactive multi-page web application built for **RDT We Do It All**, based in **7 Octopus Arm, Richards Bay, KwaZulu-Natal, South Africa**.

Owner-supervised by **Rudi Snyman** (Technical Lead) & **Dr. Tania Snyman** (Client Relations & Bookings).

---

## 🌟 Key Features

1. **Interactive 3D Architectural Home Visualizer:**
   * Real-time WebGL / Three.js 3D cutaway home model.
   * 7 interactive 3D hotspot pins corresponding to the 7 core domestic trades.
   * Unobstructed side-by-side inspector panel with technical specs and instant WhatsApp triggers.

2. **The 7 Husband-Approved Core Domestic Disciplines:**
   * **Domestic Electrical Work & COC:** SANS 10142-1 certified distribution board upgrades, rewiring, surge protection & official COCs.
   * **LPG Domestic Gas Installations & COC:** LPGSA Registered Installer for gas geysers, hobs, leak testing & legal gas COCs.
   * **Solar Energy & Power Backup:** Tier-1 monocrystalline panels, Sunsynk/Deye hybrid inverters, LiFePO4 battery storage, Stage 6 load-shedding resilience.
   * **Construction & House Revamping:** Roof repairs, coastal waterproofing, ceiling replacement (Rhino board / PVC), drywall room divisions.
   * **Fixing of Pipes & Drainage:** Burst pipes, leak detection, high-pressure drain clearing, geyser valve replacements.
   * **House Security & Alarm Installations:** Paradox / IDS systems, wireless PIR motion sensors, outdoor perimeter beams, smartphone alerts.
   * **Electric Fencing & Perimeter Security:** Nemtek wall-top & free-standing electric fences, energizers, Electric Fence System COCs (EFC).

3. **Solar & Load-Shedding Savings Engine:**
   * Interactive Eskom monthly bill slider (R1,500 to R12,000+).
   * Calculates required solar kW array, hybrid inverter sizing, lithium storage, and Stage 1–6 runtime.
   * 1-click WhatsApp quote generator pre-filling system specifications.

4. **Statutory South African Compliance Hub:**
   * Explains legal mandates under the Occupational Health & Safety Act (OHSA) and Pressure Equipment Regulations (PER).
   * Highlights why uncertified work voids home insurance claims in South Africa and delays Deeds Office property transfers.

5. **Authentic Richards Bay Fleet Showcase:**
   * Real photo of Rudi Snyman with the branded RDT truck and paving work on-site.
   * Interactive Before & After comparison slider demonstrating ceiling and modernization revamps.

6. **Interactive Multi-Trade Quote Generator:**
   * Allows homeowners to select any combination of trades and dispatch a formatted quote to Tania or Rudi with a celebratory confetti effect.

7. **Direct WhatsApp & Phone Dispatch:**

## 🛠️ Tech Stack

* **Framework:** React 19 + TypeScript + Vite
* **Routing:** React Router v7 (`react-router-dom`)
* **Styling:** Tailwind CSS v4 + Custom Obsidian & Solar Amber Design Tokens
* **3D Graphics:** Three.js / WebGL
* **Icons:** Lucide React
* **Micro-interactions:** Canvas Confetti

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/waiz2411/RDT-Solar.git
cd RDT-Solar

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
